# Security policy

This repository is a synthetic reference project, not a production payment service. Do not submit real payment data, secrets, access tokens, or customer identifiers. Do not connect the sample pipeline to production systems.

For issues in the demonstration code, open a GitHub issue with a minimal reproducer and synthetic data. Never publish secrets or sensitive payloads. Production adaptations should use the payment provider's official SDK, undergo security review, and independently validate transaction, tenant-isolation, and replay guarantees.
